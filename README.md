# genius-p3-2

Genius 論理・表現 II Part III Unit 2「Creating Something New in Empty Spaces — Presentation ①」プレゼンテーション練習アプリ（ハンドアウト準拠）

- `index.html` … ① Model（Nicole のプレゼン）：ハンドアウトの Model [Listening] 穴埋め（20か所）、シャドーイング・採点（Introduction / Body / Conclusion 別練習）、聴衆との Q&A
- `structure.html` … ② p.79 Logic and Structure：Think It Through 穴埋め、Functions 表現の暗唱、★Functions 3文＜小テスト＞（ノーミスで合格）、Figure It Out
- `listen.html` … ③ pp.80-81 Put It Together（Haruto のプレゼン）：強勢・スライド提示タイミング・ポーズを意識した Listen、スライド並べ替え、Recite 採点＋Check Points、Q&A 練習
- `mypresentation.html` … ④ Try It Out：トピック選択 → 構想メモ → Outline・スライド計画 → 200語・3パラ構成の原稿 → 発表練習・採点 → Rewrite（ブラウザに自動保存）

推奨ブラウザ：Chrome / Edge（音声認識・音声合成を使用）。🎧 ヘッドフォン推奨。
